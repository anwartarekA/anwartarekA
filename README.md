## 👨‍💻 About Me

I'm a software engineer and full-stack developer specializing in the **MERN** and **PERN** stacks. I design and build REST APIs and real-time applications with **Node.js, Express and NestJS**, and create modern user interfaces with **React, Next.js and Remix**, backed by both SQL and NoSQL databases.

- 🎓 Graduate of the **Faculty of Engineering, Computer and Control Systems Department**, Mansoura University
- 🧩 Competitive programmer on Codeforces, Codewars and LeetCode
- 🔌 Experienced with real-time communication using **Socket.IO**
- 🐳 Containerizing applications with **Docker**
- 🌱 Continuously learning new technologies and software engineering best practices
